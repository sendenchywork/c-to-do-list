# CLI To-Do List (C Project)
Консольное приложение на языке Си для управления списком задач. Проект разработан для практики работы с динамической памятью, файловым вводом-выводом и аргументами командной строки в кроссплатформенной среде (Windows / Linux).
## Возможности программы
Программа реализует главные функции To-Do Листа: 

  - Чтение списка задач
  - Добавление новых задач
  - Редактирование характеристик задач
  - Изменение статуса выполнения задач
  - Удаление задач

## Техническая архитектура
- **Структура данных:** Задачи и их характеристики записываются в заранее заданный файл `tasks.csv`. В случае отсутствия файла программа работает с *чистыми данными*.
- **Интерфейс программы** реаализован в консоли Операционной системы, а **Управление программы** производится через ручной ввод команд.
- Каждая задача имеет следующие характеристики:
  - `Название` (Строковый формат)
  - `DeadLine` (Дата и Время)
  - `Состояние` (Boolean)
  - `Описание` (Строковый формат)

## Использование
### Добавление задачи
```
# Добавление задачи
./todo add "Настроить синхронизацию через Git"

# Добавление задачи с DeadLine
./todo add "Настроить синхронизацию через Git" -dl 12.10 20:00

# Добавление задачи с описанием
./todo add "Настроить синхронизацию через Git" -dcp "Информацию найдёшь в папке ..."
```
### Вывод списка задач
```
./todo list

#|        Название           |   DeadLine   |   Состояние  |
#|[1] Настроить программу... |  12.12 20:00 |   Выполнено  |
#|[2] Сделать зарядку        |  09.12 12:30 |  В процессе  |
#|[3] Сходить в магазин з... |  07.12 10:00 |   Выполнено  |

```
### Удаление задачи
```
./todo rm

#|        Название           |   DeadLine   |   Состояние  |
#|[1] Настроить программу... |  12.12 20:00 |   Выполнено  |
#|[2] Сделать зарядку        |  09.12 12:30 |  В процессе  |
#|[3] Сходить в магазин з... |  07.12 10:00 |   Выполнено  |
#Выберите номер задачи:
1
#Вы уверены, что хоитите удалить задачу "Настроить программу на языке Си" [Y\n]
Y
#Задача успешно удалена

```
### Выполнение Задчи
```
./todo done 1
#Задача "Настроить программу на языке Си" Выполнена. Поздравлячю!

```
### Изменение характеристик
```
./todo change

#   2) Описание
```
